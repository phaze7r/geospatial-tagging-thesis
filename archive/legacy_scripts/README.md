# Legacy Scripts

This folder contains scripts that have been superseded by the "Extended" pipeline (12-city support).

## File Descriptions

- **01_collect_data.py**: Original single-city data collection.
- **01_collect_data_multicity.py**: Precursor to the extended pipeline.
- **02_preprocess_data.py**: Basic preprocessing without enhanced Roman Urdu normalization.
- **03_pattern_mining.py**: Standard FP-Growth (replaced by Guided FP-Growth).
- **04_embedding_classification.py**: Baseline embedding/classification script.
- **05_bayesian_net.py**: Original BEN implementation (replaced by hybrid model).
- **06_xai.py**: Original XAI script.
- **generate_doc_report.py**: Old report generator.
