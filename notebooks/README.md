# Geospatial Tagging of Volunteered Place Descriptions
MS-AI Thesis by Faizan Shah Ahmad, Air University, Islamabad

This repository contains a hybrid, interpretable ML framework to map informal and multilingual place descriptions to OSM tags, with a pilot focused on Islamabad, Pakistan.

Project structure:
- data/ (raw, processed, interim)
- results/ (plots, metrics)
- models/ (saved models)
- notebooks/ (Jupyter notebooks)
- scripts/ (utility scripts)
- docs/ (dataset card, preprocessing, reports)

Run notebooks in order:
- Notebook 0: Environment setup and scaffolding
- Notebook 1: Data audit and schema alignment
- Notebook 2+: Pattern mining, feature selection, modeling, XAI

All data usage follows OSM and Wikipedia licensing and platform guidelines.
