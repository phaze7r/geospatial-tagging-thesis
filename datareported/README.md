# Data Reported

This directory contains the artifacts generated by the Thesis Comparative Analysis Pipeline.

## Directory Structure
- **`raw/`**: Contains raw OSM data from Overpass API (collected via `autoscripts/01_collect_data_extended.py`).
- **`data_prepared/`**: Intermediate processed files.
- **`output/`**: Model outputs.

## Pipeline Artifacts
1. **`final_enriched_dataset.csv`**: The "Master Dataset" for the comparisons.
   - Merges `raw/*.csv` POIs with scraped Context snippets (Wikipedia/Reddit).
   
2. **`dataset_baseline.csv`**:
   - Features: Single Nouns (e.g., "Food", "Park").
   - Logic: Supervisor's Algorithm 1.

3. **`dataset_hybrid.csv`**:
   - Features: Adj+Noun Compounds (e.g., "Spicy Food", "Green Park").
   - Logic: FP-Growth (Support > 0.05).

4. **`comparison_report.csv`**:
   - The final KPIs: Hit@k, F1, ENN, Geospatial Error.

5. **`shap_explanation.png`**:
   - XAI visualization showing why the Hybrid model predicted a location.
