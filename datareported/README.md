# Data Reported

This directory contains all data artifacts generated by the Extended Geospatial Tagging Pipeline.

## Structure

- **raw/**: Raw JSONL and CSV data collected from Overpass API for each city.
- **preprocessed/**: Cleaned, normalized, and merged datasets with POS tags.
- **fp_growth/**: Output of Frequent Pattern Mining (Adj-Noun patterns).
- **ben_features/**: Selected features from Bayesian Elastic Net.
- **embeddings/**: Serialized DistilBERT and Word2Vec models/embeddings.
- **classification/**: Classification reports, confusion matrices, and benchmark results.
- **xai/**: Explainable AI visualizations (SHAP plots).

## Note
Do not manually edit files in this directory as they are auto-generated by the `autoscripts`.
